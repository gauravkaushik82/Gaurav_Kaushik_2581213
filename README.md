## How to contribute

1. Fork this repository and clone your fork.
2. Create a branch named `feature/<your-name>-<change>`.
3. Commit using Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`).
4. Push the branch and open a pull request describing what you changed and why.
